## 6. External findings (docs/research/2026-10-27-d435-docs.md, -prior-art.md)
- Jazzy realsense2_camera 4.59.1 / librealsense 2.59.1 current; Pi has 4.58.4 / 2.58.4 (probed). Current launch arg names valid; enable_accel/gyro redundant.
- Depth-RGB HW sync needs equal fps; 848x480x90 + 30 fps colour loses it.
- align/pointcloud/filters are host-CPU software; aligned depth is cropped to colour FOV (69x42 vs 87x58).
- Frames named from camera_name; set camera_name/camera_namespace explicitly, URDF parent link to <name>_link.
- Min-Z: 195 mm @848x480, 150 mm @640x360, 120 mm @480x270.
- Firmware >= 5.17.3.10, rs-fw-update with the node stopped; firmware not bundled.
- Pi unsupported officially; forum-only frame drop reports; Pi 5 needs 5V/5A supply for 1.6 A USB budget (D435 ~0.7 A).
- No Pi5+Jazzy D435 30 fps report found; align ran 3-4 fps on a Pi 4; topics fall to 4-5 Hz over WiFi.
- Calibration prior art: robot_calibration (Jazzy, pan/tilt head + gripper target) fits best; easy_handeye2/MoveIt calibration weaker. apriltag_ros 3.4.0 / aruco_ros 5.0.6 on Jazzy.
- In-tree ground_estimator_cpp already stronger than Nav2/laserscan alternatives; D435 has no IMU, so gravity prior from base IMU + head TF.
- Installed on Pi (probed): compressed/compressedDepth/zstd/theora image transports, depth_image_proc, point_cloud_transport, rtabmap_util.

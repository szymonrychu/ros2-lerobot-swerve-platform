## AC ref conventions

Evidence kinds (`evidence: {kind, ref}`):
- `test`: a test name or `file::name` that passes; verify-task re-runs it with the runner for the ref's package root when the command output lacks it
- `symbol`: a function or class the diff adds or changes; ref is `file::symbol` or the symbol
- `command`: a shell command run with `bash -lc`; passes on exit 0
- `doc-section`: `<file>#<heading>` exists as a markdown heading
- `judgement`: no mechanical proof; a reviewer decides

A `test` ref is `file::name` with the file path relative to the repo. A ref whose path is not a file is looked up by basename among the diff's changed files, then `git ls-files`.
Package runner rule: the ref runs from its package root (the nearest dir holding pyproject.toml, package.json or package.xml): pytest (uv run --frozen when uv.lock exists) for .py, vitest or `node --test` for .js/.mjs/.cjs/.ts, bats for .bats.
